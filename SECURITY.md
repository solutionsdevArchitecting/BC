# Security policy

## Reporting a vulnerability

Do not report suspected vulnerabilities in public issues or pull requests. Contact the repository security owner privately using the organization's approved security reporting channel. Include affected app/version, impact, reproduction steps, and any suggested mitigations; avoid attaching production data or secrets.

## Handling

The security owner will acknowledge the report, coordinate triage and remediation, and arrange disclosure after a fix is available. Do not publicly disclose details before coordination is complete.

## Secure development

Follow `docs/standards/security-and-privacy.md`. Never commit credentials, tokens, personal data, or production configuration.
