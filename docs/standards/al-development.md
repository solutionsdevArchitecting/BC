# AL development

- Keep each app independently buildable and declare only necessary dependencies.
- Use the team's agreed object-ID allocation, naming, formatting, and analyzer rules.
- Prefer standard events and supported extension points; avoid modifying base application behavior through brittle workarounds.
- Keep permissions least-privilege and test authorization-sensitive behavior.
- Add automated tests for business rules and upgrade-sensitive behavior.
- Build with the target Business Central symbols and review all compiler and analyzer diagnostics.
- Document app purpose, dependencies, supported platform/application version, and deployment considerations.
